================
of_wizville_base
================


- Ce module sert à implémentater de l'api Wizville :

- Ajout du champs of_product_type dans product.supplierinfo
- Ajout du champs of_product_type dans la fiche produit (related avec celui de product.supplierinfo)
- Ajout du champs of_wizville_code dans la fiche de société
- Ajout d'un onglet "informations wizville " sur la fiche contact qui contient :
   * l'info de satisfaction global
   * Score NPS
   * Date d'envoi NPS
   * Date de réponse NPS



ssh-keyscan -t rsa sftp.wizville.fr >> ~/.ssh/known_hosts
