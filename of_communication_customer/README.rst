=================================
OF Company communication customer
=================================

Module de gestion des message entre base 
Module enfant (pour les bases filles) 

Information sur le module
#########################

But
---

Ce module permet de recevoir des messages (note de patch, alerte de maintenance, etc.) envoyer par OpenFire 

Vues
----

Ce module modifie la vue liste de OF Company communication en désactivent des fonctionnalités spécifiques
Ce module modifie la vue formulaire de OF Company communication en désactivent des fonctionnalités spécifiques
