=================
OF Sale discount
=================


Fonctionnalités
################

* Possibilité d'utiliser une formule pour la remise des lignes de commande et sur les liste de prix de type "Pourcentage"
    - la formule accepte l'operation "+", interprétée comme un cumul de remises successives (il ne s'agit donc pas d'une addition mathématique).
    - le champ standard "Remise" des lignes de commande/facture est remplacé par un champ fonction pour récupérer la valeur de la remise calculée par la formule

* Ajout d'un paramètre sur la configuration de la Comptabilité pour activer la remise cumulée sur les factures


Droits utilisateurs
###################

* Ajout d'un groupe **"Remise sur ligne de facture"**
    - ce groupe permet d'afficher le champ remise sur les lignes de facture
