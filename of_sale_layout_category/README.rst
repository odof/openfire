=======================
OF Sale Layout Category
=======================

Module d'ajout des sections avancées et du nouveau widget pour les affichées.


Fonctionnalités
###############

Création de 2 nouveaux widgets
------------------------------

* Ces widget permettent de gérer les sections avancées :
    - Il en existe un pour les lignes de commande, qui permet la modification;
    - Il en existe un pour les lignes de facture, qui permet seulement l'affichage;


Création d'un wizard de synthèse des sections avancées
------------------------------------------------------

* Permet l'affichage d'un résumé des sections avancées. Comprenant un tableau avec les différents totaux par section.


Droits utilisateurs
###################

* Le wizard de synthèse est disponibles pour tous les utilisateurs internes


Reporting
#########

* Les rapports Devis/Commandes et Facture affichent la hiérarchisation des sections avancées
