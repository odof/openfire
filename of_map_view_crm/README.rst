=====================
OF map view crm
=====================

Module pour ajouter la vue map aux opportunités


Fonctionnalités
###############

Lead/Opportunité
----------------

* Activation de la vue map pour les opportunités

* Ajout de champs spécifiques pour la pop-in de la vue map:
    - Numéros de téléphones séparés par des virgules
    - Étiquettes séparées par des virgules
