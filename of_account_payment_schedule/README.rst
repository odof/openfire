===========================
OF account payment schedule
===========================


Fonctionnalités
###############

* Ajout d'un échéancier de paiements visible dans la facture client.
    - l'échéancier se calcule en fonction des conditions de règlement du facture client.

* Possibilité d'afficher l'échéancier dans le rapport facture via les options d'impression. dans **"Paramètres > Facturation > Options d'impression > Définir les options à afficher"**
