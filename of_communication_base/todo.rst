========================
OF Company communication
========================

Ceci est une liste d'amélioration possible pour ce module

Amélioration
############

Communication (`of.communication.message`)
------------------------------------------

* Ajout du choix de qu’elles groupes vont recevoir le message/notification

* Ajout du choix de quelles bases vont recevoir le message/notification

* Ajout du choix de quelles serveurs vont recevoir le message/notification

* Ajout du choix de quelles base, en fonction de leur possession de tel ou tel module, vont recevoir le message/notification

* Ajout sécurité : seul le créateur du message peut modifier le message ?

* Modifier le style du message (celui qui apparaît quand on clique sur voir plus) ?

* Communication interne pourrait être directement un autre module qui hérite de celui ci ?
