========================
OF Company communication
========================

Module de gestion des message entre base 
Module parent (pour les bases mère) 

Information sur le module
#########################

Models
------

Ce Module apporte le model of_communication_message pour crée un message sur la base parent
Ce Module apporte l'héritage du model ir_config_parameter pour rajouter des paramètre de configuration

Data
-----

Ce Module apporte un paramètre de configuration pour modifier le delay de base entre la fin et le début d'une publication d'un message 

Vues
----

Ce Module apporte un chemin pour acceder a l'application dans la bare de navigation nommé Communication OpenFire
Ce Module apporte une vue pour afficher tout les messages dans une liste
Ce Module apporte une vue formulaire pour crée/modifier un message

Sécurité
--------

Ce module apporte une sécurité de CRUD ou tout les user on tout les droit

Traduction
----------

Ce module apporte une traduction en français
