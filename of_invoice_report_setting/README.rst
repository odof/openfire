=========================
OF invoice report setting
=========================


Fonctionnalités
###############

* Modification du rapport Facture pour y intégrer toutes les options d'impression
    - il est possible d'afficher plusieurs éléments dans le rapport Facture comme :
        - les informations client (adresse, téléphone, email, etc.);
        - les informations du vendeur (nom, téléphone, email, signature, etc.);
        - les informations des lignes de facture (référence, montant HT/TTC, etc.).

* Ajout d'une fenêtre de configuration dédiée aux paramètres d'impression


Paramètres de configuration
###########################

* Ajout d'une fenêtre de configuration pour les paramètres d'impression à afficher dans le rapport Facture
  - cf "Paramètres > Facturation > Impression PDF".
