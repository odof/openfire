======================
OF Connector Poujoulat
======================

Ce module permet de transmettre une commande d'achat vers la plateforme d'achats de Poujoulat.

Fonctionnalités
###############

* Gestion des Commandes :
    -Ajoute des champs spécifiques aux commandes d'achat pour identifier les partenaires et les produits Poujoulat.

* Envoi des Commandes :
    - Automatise l'envoi des informations des articles vers le serveur Poujoulat via des requêtes, tout en gérant les réponses et les erreurs.


Paramètres de configuration
###########################

* Ajout de paramètres de configuration pour Poujoulat :
    - Voir "Paramètres > Paramètres des connecteurs > Poujoulat"
    - Les paramètres sont :
        - Adresse du serveur;
        - URL de redirection;
        - Fournisseurs;
        - Marques;
