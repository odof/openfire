===========
OF planning
===========

Module vue permettant l'activation d'une vue de planning par ressource pour les interventions.


Fonctionnalités
################

* Ajout d'un nouveau type de vue de planning (vue de planning par ressource)


Paramètres de configuration
###########################

* Ajout d'un menu "Interventions > Configuration > Paramètres" pour permettre d'accéder aux paramètres de configuration de la vue de planning
