=============
OF Sale Type
=============

Module de lien entre les type de vente et les modèle de devis/commande.


Modèle de devis/commande
------------------------

* Ajout du type de devis dans le modèle de devis/commande


Ventes
------

* Lors de la sélection d'un modèle de devis/commande, le type de vente est automatiquement sélectionné
