===========================
OF map view partner account
===========================

Module de lien entre of_map_view_partner et le module account pour rajouter le type map sur les vues clients et fournisseurs


Fonctionnalités
###############


Clients
-------

* Activation de la vue map sur les clients dans les menus de facturation


Fournisseurs
------------

* Activation de la vue map sur les fournisseurs dans les menus de facturation
