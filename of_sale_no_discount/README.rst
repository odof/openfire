===================
OF Sale no discount
===================


Module OpenFire pour gérer la remise interdite sur les ventes.
---------------------------------------------------------------

Ajout d'un champ sur le fiche produit pour indiquer si la remise est interdite sur la vente.

Si la remise est interdite, le champ de la remise est grisé et la remise est automatiquement à 0.
Pour un profil utilisateur qui n'est pas "Responsable" ou "Administrateur" des ventes de modifier
le prix unitaire et la remise sur une ligne de vente.
Pour un profil utilisateur qui est "Responsable" ou "Administrateur" des ventes, il peut modifier le prix unitaire
d'un produit mais pas la remise.
