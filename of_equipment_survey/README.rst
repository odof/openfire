===================
OF Equipment Survey
===================

Module de liaison entre les équipements et les questionnaires pour OpenFire.


Fonctionnalités
###############


Questionnaire (`of.survey.survey`)
----------------------------------

* Ajout d'un type de questionnaire "Questionnaire d'équipement".


Rapport d'équipement (`of.equipment.intervention.report.template`)
------------------------------------------------------------------

* Ajout d'un champ questionnaires sur le rapport d'équipement.
    - Ce champ permet de lier un questionnaire à un rapport d'équipement.
    - Les questionnaires liés sont affichés sur le rapport d'équipement.
    - Les réponses aux questionnaires sont enregistrées sur le rapport d'équipement.

* Il est possible de répondre aux questionnaires liés depuis le rapport d'équipement.


Reporting
#########

* Modification du rapport d'équipement pour afficher les questionnaires liés.
