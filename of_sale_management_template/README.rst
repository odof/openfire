===========================
OF sale management template
===========================


Fonctionnalités
################

Modèle de devis
---------------

* Ajout d'un champ **Condition de paiement** sur les modèles de devis
* Ajout d'un champ **Position fiscale** sur les modèles de devis
* Ajout d'un champ **Documents joints** sur les modèles de devis

Devis / bon de commande
-----------------------
* Ajout d'un champ "of_documents_ids" sur les devis / bon de commande
* Remplir les champs 'of_documents_ids' , 'fiscal_position_id', et 'payment_term_id' à partir de modèle de devis choisis
